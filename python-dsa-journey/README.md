# Python DSA Journey

MCA student's Data Structures & Algorithms learning log in Python -
reordered for a beginner-to-interview-ready progression, using
freeCodeCamp's "Data Structures and Algorithms in Python" course as
the primary reference, with topics resequenced and extra practice
problems added per topic.

## Resource
**Course:** freeCodeCamp - Data Structures and Algorithms in Python (Full Course)
**Video:** https://youtu.be/pkYVOmU3MgA

## How this repo is organized
- `01-big-o-complexity/` ... `16-shortest-paths/` - one folder per topic,
  in learning-progression order (not the video's original order).
  Each has a README with notes and 2-3 practice problems (Easy/Medium/Hard),
  added day by day.
- `projects/` - a full interview-style problem walkthrough, plus ongoing
  interview prep notes.
